# 海洋与大陆（ocean）

`earthengine.ocean` 负责**全球地理结构**：大陆布局、大陆架、海平面。

## 大陆布局（basins.py）

`build_continents_validated` 生成“像地球的全球大陆规划”，默认结构：

1. **一个超级大陆**（约 30–40% 陆地，形状/海湾/半岛/裂谷每次随机变化）；
2. **2–3 个独立中型大陆**（约 35–45% 陆地，与超大陆保持真正海洋间隔）；
3. **一个澳大利亚型大陆**（明确独立约束：`AUSTRALIA_MIN_OCEAN_GAP_DEG`，
   周围为大洋、不与其他大陆相连、面积较小）。

布局由“模板 + 随机扰动”实现：Earth-like 约束 + 随机种子 + 可控扰动，
每个 seed 得到不同的地球。陆地占比 `LAND_LO–LAND_HI`（0.25–0.35）。

## 宏观地理验证器（pipeline/geography_validator.py）

生成大陆后先验证再进入下一步，检查：

- 陆地占比 ∈ [0.25, 0.35]
- 主大陆数量 ∈ [4, 7]
- 最大大陆 ≥ 25% 陆地（存在主导超大陆）
- 至少一个隔离大陆（Australia-like，海岸-海岸角距 ≥ 5°）
- 最大洋盆 ≥ 25% 球面
- 大陆凝聚（碎片化 ≤ 3%，无拼图感）

失败 → 重滚布局参数重新生成，而非修补地图。

## 大陆架（shelves.py）

由地壳类型 + 距陆缘推导（非高程硬切），实现大陆架连续过渡。

## 海平面（sea_level.py）

`ocean_fraction_to_sea_level` 由目标海洋占比对高程直方图二分反推海平面；
`apply_sea_level` 应用到高程。陆地占比被**确定性强制**（flood 低海岸地）。
